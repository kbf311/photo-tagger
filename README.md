# Photo Tagger (写真自動タギングツール)

AI（RAM++: Recognize Anything Plus Model）を活用し、写真に写っている被写体・情景・属性を認識して自動でタグ付けを行い、CSVファイルへ出力するツールです。

大量の写真の整理、検索用キーワードの抽出、画像管理データベースのメタデータ作成などに利用できます。

---

## 主な特徴

- **高性能な画像認識**: 最新のビジョンAIモデル（RAM++）により、幅広い被写体や状態・シーンを高精度にタグ付けします。
- **サブフォルダの一括スキャン**: 指定したフォルダ配下のサブフォルダに含まれる画像も再帰的に探索してまとめて処理します。
- **柔軟な設定**: 検出の厳しさ（しきい値）、1枚あたりの最大タグ数、出力したくないタグ（除外リスト）を簡単に調整できます。
- **自動モデルダウンロード**: 初回実行時に必要なAIモデル（約1.5GB）を自動で取得します。
- **エラー耐性**: 破損した画像ファイルは自動的にスキップされ、全体の処理が途中で止まりません。

---

## 動作要件

| 項目 | 要件 |
| :--- | :--- |
| **OS** | Windows 10 / 11 (64bit) |
| **ハードウェア** | NVIDIA製 GPU（GeForce RTXシリーズ等、VRAM 8GB以上推奨）<br>※ CPUのみでも動作しますが処理速度が大幅に低下します |
| **前提ツール** | パッケージマネージャー `uv` |
| **対応画像形式** | `.jpg`, `.jpeg`, `.png`, `.webp`, `.bmp` |

## 初回セットアップ

本ツールでは高速な Python 管理ツール **`uv`** を使用します。

### 1. `uv` のインストール（未導入の場合のみ）

キーボードの `Windows キー` を押し、`powershell` と入力して PowerShell を起動し、以下のコマンドを貼り付けて実行してください。

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

※ インストール完了後、PowerShell は閉じて構いません。

### 2. 環境構築スクリプトの実行

1. 本ツールのフォルダ内にある **`run_setup.bat`** をダブルクリックして実行します。
2. インストールモードの選択肢が表示されます。
   ```text
   [1] requirements.txt
       - パッケージを最新バージョンでインストールします (通常はこちらを推奨)
   [2] requirements-lock.txt
       - 動作確認済みの固定バージョンでインストールします
   ```
   通常はそのまま **`1`** を入力（または未入力のまま Enter）してください。
3. 必要なコンポーネントが自動的にダウンロード・セットアップされます。
4. 「セットアップが正常に完了しました！」と表示されたら、何かキーを押して画面を閉じます。

## 使い方

### 最も簡単な方法（デフォルトフォルダを使用）

1. タグ付けしたい写真や画像を **`input`** フォルダ内にコピーします（サブフォルダごと入れても問題ありません）。
2. **`run_app.bat`** をダブルクリックして実行します。
   - ※ 初回のみAIモデル（約1.5GB）のダウンロードが行われます。完了まで数分お待ちください。
3. 処理の進捗バーが表示され、すべての画像の処理が終わると自動的に完了サマリーが表示されます。
4. **`output/tags.csv`** に結果が出力されます。

---

### 設定ファイル (`paths.yaml`) でフォルダを指定して実行する場合

コマンドライン引数を入力せずに、特定のフォルダを自動処理したい場合は **`paths.yaml`** にパスを記述しておきます。
（`paths.yaml` は個人環境のパスを含むため、`.gitignore` の対象となっており Git リポジトリにはコミットされません）

1. フォルダ直下の **`paths.yaml`**（存在しない場合は `paths.yaml.example` をコピーして作成）をテキストエディタで開きます。
2. `target_dir` に処理対象のフォルダパスを記述します。
   ```yaml
   # Windowsのパスはシングルクォートで囲むのが確実です
   target_dir: 'D:\写真\2026年旅行'
   # またはスラッシュ形式、相対パスでも指定可能です
   # target_dir: "D:/写真/2026年旅行"
   # target_dir: "input"
   ```
3. **`run_app.bat`** をダブルクリックするか、ターミナルで引数なしで実行します。
   ```powershell
   .venv\Scripts\activate
   python main.py
   ```

---

### 任意のフォルダを引数で指定して実行する場合（コマンドライン）

コマンド実行時に直接フォルダを指定することも可能です（`paths.yaml` の設定よりも引数が優先されます）。

1. 本ツールのフォルダでターミナル（PowerShell または コマンドプロンプト）を開きます。
2. 以下のコマンドを実行します（対象フォルダのパスを二重引用符で囲んで指定してください）。

```powershell
# 仮想環境を有効化して実行
.venv\Scripts\activate
python main.py "D:\写真\2026年旅行"
```

## 出力結果について

処理が完了すると、**`output/tags.csv`** に結果が保存されます。

### CSVのフォーマット

| 列名 | 内容 | 例 |
| :--- | :--- | :--- |
| **パス** | 画像ファイルが保存されているフォルダの絶対パス | `D:\Projects\photo-tagger\input` |
| **ファイル名** | 対象の画像ファイル名 | `EK001_L.jpg` |
| **タグ** | 認識されたタグ（` \| ` 区切り、信頼度が高い順） | `car \| road \| highway \| city \| building` |

> [!NOTE]
> 出力される CSV ファイルは **UTF-8（BOMなし）** 形式で出力されます。
> Excel で開いた際に文字化けする場合は、Excel の「データ」タブ →「テキストまたは CSV から」を選択して UTF-8 でインポートするか、対応するエディタ（VS Code、メモ帳、サクラエディタ等）をご利用ください。

## 設定のカスタマイズ (`config.yaml`)

フォルダ直下にある **`config.yaml`** をメモ帳などのテキストエディタで開いて編集することで、動作をお好みに合わせて変更できます。

```yaml
# 信頼度しきい値 (0.00 〜 1.00)
# 数値を高くする (例: 0.75) と、確度の高いタグのみに厳選されます。
# null に設定すると、モデル標準の最適化しきい値が使われます。
threshold: 0.68

# 1画像あたりの最大出力タグ数
# 0 または null: 検出されたすべてのタグを出力
# 20 などの数値を指定: 信頼度の高い順に上位20件のみを出力
max_tags: 0

# 除外したいタグのリスト (ブラックリスト)
# 出力に含めたくないタグがある場合はここに追加します (大文字小文字は区別されません)
excluded_tags:
  - "photo"
  - "image"
  - "picture"

# 使用するデバイス
# "cuda": NVIDIA GPU を使用 (推奨)
# "auto": GPUが使える場合はGPU、使えない場合は自動でCPUに切り替え
# "cpu": CPU のみを使用
device: "cuda"

# バッチサイズ (一度に並列処理する画像枚数)
# GPUのVRAM容量に合わせて調整してください。
# RTX 4060 / 5060 Ti (16GB) クラス: 16 〜 32
# VRAM 8GB クラス: 4 〜 8
batch_size: 16
```

## よくある質問・トラブルシューティング

### Q. GPU メモリ不足エラー (CUDA Out of Memory) が発生する
- `config.yaml` の `batch_size` を小さな値（例: `8` や `4`）に変更してください。
- 他に VRAM を消費しているアプリケーション（動画編集ソフトやゲームなど）を終了してから再実行してください。
- 本ツールにはメモリ不足時に自動で1枚ずつの推論に切り替える保護機能が備わっていますが、バッチサイズをあらかじめ下げておくことでより安定して高速に動作します。

### Q. 「photo」「image」「blur」などの当たり前の単語を省きたい
- `config.yaml` の `excluded_tags` 欄に除外したい単語を追加してください。

### Q. 「uv がインストールされていない」というエラーが出る
- 「[初回セットアップ](#初回セットアップ)」の手順 1 を参考に、PowerShell から `uv` をインストールしてください。

### Q. タグは日本語で出力されますか？
- 現在は英語のタグ（`car`, `highway`, `tree` など）が出力されます。
